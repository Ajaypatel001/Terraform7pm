# Terraform – Infrastructure as Code (IaC)

## 📌 What is Terraform?
Terraform is an open-source **Infrastructure as Code (IaC)** tool created by HashiCorp.  
It is used to create, update, and manage cloud infrastructure using simple configuration files.

With Terraform, we write code to manage infrastructure instead of creating it manually.

---

## 🎯 Why Terraform is Used?
Terraform is used to:
- Automate infrastructure creation
- Manage cloud resources using code
- Avoid manual configuration errors
- Create same infrastructure again and again
- Save time and effort

---

## 🛠️ What We Do in Terraform?
In this project, Terraform is used to:

- Create cloud infrastructure
- Manage resources automatically
- Use reusable configuration files
- Maintain infrastructure state

---

## 📂 Terraform Components Used

- **Provider** – Connects Terraform to cloud (AWS)
- **Resource** – Creates cloud resources
- **Variables** – Make code dynamic
- **Output** – Display important values
- **State File** – Tracks infrastructure state

---

## ☁️ Cloud Provider Used
- AWS (Amazon Web Services)

---

## ⚙️ Terraform Workflow

1. **terraform init**  
   Initialize the project and download providers

2. **terraform plan**  
   Show what changes will be made

3. **terraform apply**  
   Create or update infrastructure

4. **terraform destroy**  
   Remove all resources
